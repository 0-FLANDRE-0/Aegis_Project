# 남은 최적화 순서

PERF_B는 교전 판단 내 미래 관측/SPG 기하 반복과 정확히 같은 owner 자세의 body frame 생성 비용을 줄인다. 다음 순서는 최신 profiler와 대표 부하를 기준으로 조정한다.

1. **SPY 관측 연관**: 반복 covariance/Jacobian 전처리·NIS 후보 행렬과 할당 비용을 감사한다. NIS gate·배정/후보 순서·tentative/confirmed·관측 authority와 RNG를 보존한다.
2. **피격 순간의 지연**: CG envelope cross-section 정렬/convex를 실제 접촉 조건으로 분리 측정한다. 임의 좌표 반올림으로 접촉 순서나 피해를 바꾸지 않는다.
3. **3D·효과와 최종 재측정**: 기존 LOD/smoke batching을 기준으로 카메라에 보이는 다수 탄체/잔해/효과의 CPU·draw·resource 비용을 측정한다. 공유 geometry/instancing은 owner·동적 재질·disposal 수명을 검증한다.

헬기/초수평선 탐지와 사용자 지정 **RGM-109E Block Va**는 총 최적화 뒤다. 물리/센서 주기나 방어 기능을 줄이는 방식은 쓰지 않는다. 소프트웨어 GPU 호스트 관측을 사용자 휴대폰 FPS로 표현하지 않는다.
