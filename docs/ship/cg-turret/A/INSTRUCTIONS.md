## 1. 이유

- GUN_B1에서 CG 포탑에 DDG 쪽 옛 절차 생성 메시 `WIP148_EXTERNAL_3D.buildMk45`를 씌웠다. 이 메시는 현재 DDG 3D 모델(KojfDiscord 알레이버크)의 포탑이 아니며, 외형 품질이 낮다.
- 원래 CG 모델(3D Warehouse 벙커힐)의 둥근 포탑 조립체로 되돌린다.
- 실함 CG-52는 Mod 4(62구경)로 개장됐으므로 **성능은 Mod 4를 유지**한다. 외형(54구경 둥근 포탑)과 장비가 다르다는 점은 보고서와 화면 표기 근거에 기록만 한다.

## 2. 변경

1. **외형**:
   - CG 두 마운트(전·후)에서 `buildMk45` 생성 포탑을 제거한다.
   - GUN_B1 이전에 숨겼던 원래 CG 포 조립체(`mk45f_*`, `mk45a_*` 노드)를 다시 보이게 한다.
   - 선회·고각 노드 연결은 GUN_B1 이전 방식을 따른다.
   - DDG의 포탑과 `buildMk45` 함수 자체는 건드리지 않는다.
2. **포구 위치 값**:
   - CG 설치의 `trunnionOffsetM`과 `exposedBarrelM`을 GUN_B1 이전 값으로 되돌린다.
   - 되돌릴 값은 `BUNKER_REGISTRATION.guns.mk45` / `mk45Aft`의 `trunnionOffsetM`, `barrelM`이다. 참고로 전방은 trunnion (0.7914, 0.0006, 2.0284) m, barrel 5.8211 m다.
   - GUN_B1의 (.91, 0, 2.87) / 6.206 m는 제거한다.
   - 탄 발사 원점과 3D 포구 끝의 오차는 **≤ 0.1 m**여야 한다. 두 마운트 모두, 대표 고각 3개(0°, 30°, 60°) × 선회 3개에서 확인한다.
3. **유지**:
   - CG 모듈 `MK45_MOD4_CG52_MK160_V1`의 성능 값: 포구속도 823 m/s, 사통 0.8–24 km, 탄약고 600발×2, MFF/HE/SAP
   - 사계·클리어런스 판정 함수
   - UI 표기 `Mk 45 Mod 4`
   - 클리어런스는 원래 CG 메시 기하로 판정한다. 포신 길이가 바뀌어 사계가 달라지면 차이를 보고한다.

## 3. 회귀 규칙

- **DDG 전체와 함포가 개입하지 않는 CG 항목**은 B2B 기준과 **byte 동일**해야 한다.
- **CG 함포가 개입하는 항목**은 원점이 바뀌므로 달라질 수 있다. 수상 사격, 대공 G7, 단발 Pk, MAP_D 함포 흐름, CG 함포 UI 등이 해당한다.
  - 차이의 원인이 **원점 변경 하나**로 확인되면 그 기대값 갱신은 **사용자 사전 승인**으로 처리한다.
  - 확인 방법: 원점만 B1 값으로 되돌린 진단 빌드가 B2B와 동일함을 보인다.
  - 원인이 다른 차이는 갱신하지 않고 보고한다.
- 저장 스키마, ENVELOPE_TABLE_D, 보호 함수 281개는 그대로다.
