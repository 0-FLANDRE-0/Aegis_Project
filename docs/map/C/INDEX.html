## 1. 변경 요약과 기준

- 기준: `map-b` / `06d668abf457a8dd3a98659e3b4535ee69612612` / MAP_B HTML SHA-256 `6dfac8a6e846bc6476619d721d5113fdc638f309ef5ba0b568e0526010ed8c42`.
- 산출물: `Aegis_SIM_v48_WIP_MAP_C.html` / `22,030,632` bytes / SHA-256 `84fa5df960772cdb9c9904310ca7af752e3cedae025fd864dc1b27a9de6f8d7b`.
- 작업 브랜치 `map-c`. main 병합, release, tag 생성 없음. HTML ZIP과 보고서 ZIP을 분리한다. 원격 영수증은 `remote-readback.json`에 기록한다.
- UI/입력만 변경했다. 비행·유도·센서·신관·추진·발사 권한·사거리표·게임 저장 스키마는 변경하지 않았다.
- 링 라벨은 9px. 기존 요격 예측 라벨은 11px를 보존했다. 화면 밖 링 라벨은 시간 블록 아래로 내렸다.
- 교전 패널을 2줄 미니 태그로 줄였다. 주황/빨강일 때만 기존 사유 1구역을 더 표시한다. 원래 `mapCancelB`는 표적만 해제하며 터치 영역은 최소 28px다.
- 기존 시계·일시정지·배속 노드를 오른쪽 위 2줄 블록으로 이동했다. 창보다 높은 레이어를 사용하고, 원래 3D 정보/아군함 버튼은 아래로만 옮겼다.
- 원래 `mapFireB`를 하단 고정 폭 106px 슬롯으로 이동했다. 기존 리스너·명령 큐·fixed tick·정식 VLS 경로는 동일하다. 재고/EMCON/모드 칩 폭도 미리 확보해 선택·판정·라벨 길이 변화가 바를 밀지 않는다.
- 탭은 직접 선택/재탭 순환을 사용한다. 롱프레스·우클릭의 후보 목록/확대/상황 메뉴는 기존 경로다.

구현 전 결정은 [PRE_IMPLEMENTATION.md](PRE_IMPLEMENTATION.md)에 남겼다. 옛 `drawLockedTrackInfoCard`는 캔버스 카드이며 부드러운 추종 기능이 없어 다시 활성화하지 않았다. 기존 투영·경계 계산과 관측 레코드를 재사용했다.

## 4. 추종 계산과 데이터 경계

- detached 관측 프레임의 현재 위치·속도만 읽는다. 이미 EKF가 전파한 위치에 sensorAge를 다시 더하지 않는다. 고정 틱 사이의 누적기 시각만 관측 속도로 전파한다.
- 새 표시 잔차를 연속 오프셋으로 보관하고 `(1-u)^3`, `u=elapsed/150ms`로 150ms 안에 수렴시킨다. 일시정지에서는 표시 시각과 잔차 수렴 시각을 모두 동결한다.
- 선택 심볼·태그·히트 판정이 같은 표시 좌표를 사용한다. 명령용 원래 관측 레코드는 그대로여서 정밀추적/발사 입력을 표시 예측값으로 바꾸지 않는다.
- 선택 표적이 있는 PiP만 rAF로 갱신해 심볼과 태그가 다른 주기로 움직이는 일을 없앴다. 비선택 PiP의 기존 2/4/10Hz 설정은 유지한다.
- kind/identity/기존 자함 발사 확인 근거만 우선순위에 사용한다. 트랙 truth 참조, 적 배열, 실제 표적 위치, RF 물리 객체 읽기 0. 자세한 whitelist는 [data-sources.json](data-sources.json).
- transient 태그·순환 상태는 게임 저장에 넣지 않는다.

재현: `build.py` → `static_verify.cjs` → `run_domain.py` / `run_final_native.py` / `run_final_ui.py` / `verify_dom_c.py` → `acceptance.py` → `write_report.py` → `package.py`. 테스트용 관측/네트워크/발사 fixture는 보고서에만 포함하고 제품 HTML에는 넣지 않는다.
