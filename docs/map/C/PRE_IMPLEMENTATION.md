- 옛 drawLockedTrackInfoCard는 캔버스 카드이며 부드러운 추종 기능이 없다. PIP_B에서 별도 DOM 창으로 옮겼으므로 이를 다시 켜지 않는다. 기존 worldToScreen/screenToWorld, 경계 계산과 관측 레코드를 재사용한다.
- 시간 블록은 원래 노드를 창보다 높은 레이어로 이동한다. 발사 버튼도 원래 노드와 클릭 리스너를 유지한다. 발사 슬롯, 재고 항목, EMCON/교전 칩 폭을 고정해 상태 변화가 바의 다른 요소를 밀지 않게 한다.
- 우선순위는 kind, identity, 기존 확인된 자함 발사 상관 근거만 사용한다. kind=MISSILE 어댑터는 자함 무장만 공급한다. ownLaunchObserved는 기존 _harpoonOwnC.confirmed의 읽기 전용 투영이다. HOSTILE/ASSUMED_HOSTILE/UNKNOWN 및 식별 없는 ESM을 무장 선택 상태의 근접 묶음에서 우선한다. 아군/중립을 적으로 추측하지 않는다.
- 6px 근접 묶음, 12px/1.5초 재탭 기준을 그대로 사용한다. 비추이적인 정렬을 피하려고 최단 거리부터 6px씩 묶고, 그 묶음 안에서 우선순위를 적용한다. 자함 미사일은 전체 후보의 마지막이다. 후보 집합·지도·무장 선택 유무 문맥이 같을 때 첫 탭의 순서를 재사용해 순환한다. 롱프레스/우클릭의 기존 choose/context 경로는 보존한다.
- PiP 4Hz와 태그 rAF만으로는 고배속에서 심볼과 태그 간 3px를 유지할 수 없다. 선택 표적 심볼·태그·히트 테스트가 같은 표시 예측 좌표를 사용하고, 선택된 PiP를 매 프레임 갱신한다. 비선택 상태의 2/4/10Hz 설정은 유지한다.
- 표시 예측은 detached chart frame의 위치·속도와 기존 고정 틱/누적기 시각만 읽는다. 이미 EKF가 현재 시각으로 전파한 위치에 sensorAge를 다시 더하지 않는다. 새 위치 잔차는 표시 전용 오프셋으로 약 150ms 동안 수렴시키며, 일시정지에서는 예측·수렴 시간을 동결한다. 실제 트랙/KF/시뮬 상태에 쓰지 않는다.
- 소실 상태의 회색 요구는 태그 틀·본문에 적용한다. 상태원과 발사 슬롯은 기존 MAP_B의 차단 판정 빨강을 유지한다.

위 내용은 구현 전에 대화로 보고했으며, 승인 대기를 요구하지 않는 지시의 ‘보고 후 진행’에 따라 구현을 이어갔다.
