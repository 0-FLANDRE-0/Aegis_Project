# HELI_E 구현 전 계약 대조와 결정

사용자의 기존 확정을 우선하며 HELI_D를 기준으로 확인했다. 구현 전에 보고한 항목과 이후 앵커 답변을 이 파일에 고정한다.

1. **108rpm와 60Hz:** 한 틱의 회전각10.8°가 빔폭2.1°보다 크다. 순간 빔 샘플링을 폐기하고 각 틱의 통과 구간에서 Gaussian 빔을 적분한다. 반사체별 회전당 한 번의 단일 주사 검출이며, 여러 회전의 에너지 적분이 아니다.
2. **누적 의미 — 사용자 최종 결정:** PERI 단일 주사 검출 → 이진4-of-9 하나만 사용한다. 에너지9주사 누적은 제거한다. LONG/SHORT도 단일 주사 →2-of-3 하나다. 앵커Pd는35km 고정 표적의 임의의 완전한9주사 창 하나에서 확정될 확률50%다. 장기간 두었을 때 언젠가 획득할 확률을 측정하지 않는다. 마지막 주사가 miss여도 앞선 검출이 충분하면 확정한다.
3. **200접촉과64보고 queue:** H1/H2의 동일 지연 포트에 모든 접촉을 매 주사 보내면 포화될 수 있다. 각 기체32보고/초, burst24, 합계64보고/초와 queue예약8을 적용한다. 현재 batch를 순환 선택해 기아를 줄이고 초과분을 버린다. backlog/버퍼링/재전송은 없다.
4. **외형과 wire schema:** 내부 접촉 병합에서 측정 외형을 확대한다. 엄격한 `AEGIS_OFFBOARD_PLOT_C_1`에는 외형 필드를 추가하지 않는다. 위치의 신호 가중 중심과 증가한3×3 공분산으로 불확실성을 보낸다. 표적ID/truth 참조는 금지한다.
5. **수평선 표시:** 실제 RF gate는 해당 반사체/함정 프로파일의 높이를 사용한다. 알 수 없으면30m fallback. UI의30m 기준 수평선은 표적 독립적인 기하상한이며 SNR 범위와 구별한다. 계기거리는 사거리(slant), 지도/3D 원은 해면에 투영한 수평거리다.
6. **오경보 의미 — 사용자 최종 결정:** 오경보 약1회/시간도 M-of-N 통과 후 **새로 확정된 허위 접촉** 기준이다. 단일 cell의Pfa와 구별한다. 기하학적 추적 게이트가 여러 cell을 묶는 효과도 역산한다. 독립 CFAR noise-tail을 공통 RF 합성 안에서 생성하고 downstream은 실제 표적 관측과 동일한 익명 측정/게이트만 사용한다. 분산 clutter를 표적truth로 바꾸지 않는다.
7. **모드 전환/저장:** 새 모드1회전 동안 데이터가 없다. 그 모드의 누적/접촉을 비우되 모함의 기존 트랙은 일반 coast를 따른다. D1 저장의radarOn false→STBY, true→LONG, 비행 필드는 보존하며 transient는 복원하지 않는다.

기존 확정: Hawklink는 레이더EMCON과 독립이다. 통신EMCON은 Link16과 함께 다룰 후속 정책이다. IFF와 실제 현지 관측 없는 무장발사 금지, 헬기 피격·격추 후속,120초 준비/두 기/고도/경로/추종/로터/문/CAMERA는 유지한다. ISAR/ARPDD, 공중 탐색, ESM, 재밍, 섹터, 수동 틸트, 연료/무장/회수는 이번 범위가 아니다.
