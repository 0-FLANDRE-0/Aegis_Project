# HELI_F2 충돌·선행 결정

사용자에게 구현 전 별도로 보고했고, 0번을 `helicopter-emcon-f2-0`의 원본 HTML/124개 검사/원격 decoded blob 대조로 완료·별도 보고한 다음 이 단계를 시작했다.

- 기존 ISAR/ARPDD 예약 중 **ISAR만** 이번 명시 요청으로 활성화한다. ARPDD는 계속 선택 불가.
- Hawklink plot 무버퍼 원칙은 유지한다. 이번 명시 요청의 **ISAR 판독 결과만** 기체에 최대8개 보관한다. 송신 후 모함이 보유하는 정보자료는 최대16개/600초이며, 원래 측정 시각과 위치 불확실성을 유지한다. 트랙이 소멸·재획득될 때도 위치 게이트를 다시 적용하며 식별/권한은 옮기지 않는다.
- 기존 확정 정책: EMCON은 레이더 방사 통제다. Hawklink/Link16과 독립이다. 통신 EMCON은 미래 공통 단계다.
- 기존 120초 출격·고도 조절·CG 좌현 원본 슬라이딩 문/공통 좁은 출구·DDG 두 문은 그대로다.
- 기존 F1 수동 권한·트랙 나이10초·예측 바스켓·정체성·사거리·장비 관문·무DL과 0번 수동 지정은 그대로다. ISAR 정보로 track freshness/position/confirmed/hits를 높이지 않는다.
- 작전 저장의 전투 transient 복원 금지에 따라, 진행 중 ISAR는 저장하지 않고 그 직전 STBY/LONG/SHORT/PERI 설정을 저장한다. 기존 E1/J1 저장 계약을 유지한다. 진행 중 표적, 결과, 창, 링크, 식별 근거는 전투 transient다.

위 두 명시적 범위 변경 이외의 정책 변경은 없다. 로터 공력·회수·연료·ISAR 외 추가 모드/무장/ESM 노출/재밍/Link16 전송은 추가하지 않는다.
