# Source and changes

Original asset: **USS Daniel Inouye DDG-118** by **SB-129** ([author](https://sketchfab.com/hrd4588)).

Source: https://sketchfab.com/3d-models/uss-daniel-inouye-ddg-118-c577336de6264fa19912afb7ca0c6764

The uploaded GLB's `asset.extras` identifies its license as **Creative Commons Attribution 4.0 International**, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). This attribution and the original author/license/source/title metadata are retained in the extracted GLB, packed metadata, and standalone viewers.

Changes made for Aegis model audit A1: helicopter groups extracted; ship/unused textures removed; exact duplicate geometry and buffers shared; index widths narrowed losslessly; static folded/deployed/flight visibility reconstructed. The lossless GLB retains source float coordinates, normals, indices, transforms and material values. The compact HLA1 version additionally quantizes coordinates to Q16 and normals to SNORM16. The coordinate scale in metres is not certified. No affiliation or endorsement by the original creator is implied.

The standalone viewer reuses Three.js r140 from the verified Aegis PERF_F file. Three.js is distributed under the MIT license below. The compact asset loader uses the caller's existing Three.js engine when integrated into Aegis.
