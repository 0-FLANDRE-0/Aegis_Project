구현 전 사용자에게 다음 겹침을 목록으로 보고했다.

1. 이전의 순수 공유 트랙 하푼 금지는 이번 요청에서 **수동 하푼 OTH 발사만** 해제한다. SAM/함포나 전단 공유 정책을 확대하지 않는다.
2. 기존 H3 공격 AI에는 승인 capability와 현지 관측 조건이 별도로 있다. 로컬 관측 blanket denial을 제거하더라도 이 기존 AI 권한을 변경하지 않는다. `attackObservationGateH3`, `attackAuthorityH3`, `attackFinalGuardH3`는 그대로다. 수동 명령/자동 발사관 선택은 동일 native gate에서 다시 검사한다.
3. 10초는 발사 관문 제한이다. 기존 15초 외부 보고 수명, 4초 coast/18초 drop, 측정 나이 공분산 처리를 변경하지 않는다. 10초 초과에서는 MEMORY 상태보다 `SURFACE_TRACK_COAST_EXPIRED`를 먼저 반환한다.
4. 실제 충돌 결과는 `AFTER_ACTION_TRUTH` 사후 분석만 허용한다. 전술/센서/AI는 이를 읽지 않으며 하푼 비행 위치·명중 DL을 추가하지 않는다.

추가 검사에서 **DDG-119만 헬기 운용, CG-52만 Mk141**을 지원함을 발견했다. H1/H2는 원래 모함 전용이며 순수 Hawklink 트랙 Link16 재공유는 기존에 제외되어 있다. 사용자에게 플레이 연결 제약과 두 선택지를 보고했고, 사용자는 **“F1 완료 후 CG-52 헬기는 다음 단계”**를 선택했다.

따라서 이번은 기존 함정 구성을 유지한다. 실제 DDG 헬기의 SHORT/PERI/LONG RF→익명 plot→Hawklink 수신을 실행하고, 그 측정의 위치·공분산을 CG receiver에 진단 재생하여 발사 품질을 확인한다. 이것을 현재 플레이의 전단 재공유 또는 CG 헬기 지원으로 표현하지 않는다. 완전한 라이브 헬기→모함 하푼 시나리오는 CG-52 항공 운용 후속 단계다.

순수 offboard 운용자 식별은 이미 허용되어 있었으므로 식별 정책을 완화하지 않고 식별 근거 필드만 보강했다. 레이더 EMCON과 Hawklink의 독립, 기존 무장 손상·사거리·보호 식별·좌표/경로, 120초 출격과 기체·로터·고도·3D 표시 계약을 유지한다.
