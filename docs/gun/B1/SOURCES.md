# 출처와 적용 범위

- 확인: U.S. Naval Institute, Edward J. Walsh, Proceedings 2008-02, [Naval Systems: Cruiser Updates Begin](https://www.usni.org/magazines/proceedings/2008/february/naval-systems-cruiser-updates-begin). CG52 Mk45를 54구경에서 62구경 Mod4로 교체한다고 기술. 다른 레이더/CIWS 구성은 이번 작업에 가져오지 않았다.
- 확인: [U.S. Navy MK45 Fact File](https://www.navy.mil/DesktopModules/ArticleCS/Print.aspx?Article=2167864&ModuleId=724&PortalId=1), Article2167864. Mod4 탑재함 CG52–60/62–64와 순양함 1200발 제시.
- 확인한 공개 공고의 재게시본: [2016-06-20 MK419 Mod1 Special Notice](https://tendery-stran-mira.tenderguru.ru/tendery-usa/493819). Mk187의 기폭 장치, Mk34 장입기와 호환, AIR/HOB/AUTO/PD/ET 모드의 존재만 참고했다. 상세 기술자료는 사용하지 않았다.
- 지시서 참고문헌: NDIA 2012 Hendershot, 2011 Ring; [공개 회의 자료 목차](https://www.bulletpicker.com/pdf/55th-Annual-Fuze-Conference.pdf). 고속정 예시 범위를 실제 대공 유효거리로 간주하지 않는다. 9km는 사용자가 정한 게임용 자동 범위다.
- 지시서 참고문헌: DefenceTalk 2009 sea trials, NavWeaps/Mk80 3.7kg 참고. 이번 열람에서 DefenceTalk 해당 본문은 확인하지 못했다. Mod4 변경은 위 USNI/미 해군의 일치하는 자료로 확정했다. Mk187 실제 작약량/파편 제원은 주장하지 않는다.

기존 CG 근거 `CG52_2021_MK45_MOD2_PHOTO_CAPTION__5IN54_PUBLIC`는 후기 CG52의 현재 모듈 근거로 **대체됨**. 역사적 Mod2 모듈 정의와 원래 문자열 자체는 삭제하지 않았다.

823m/s·0.8~24km·드라이브/급탄/탄도 값은 이 게임에 이미 있던 Mod4 모듈을 그대로 재사용한다. 새 MFF의 신관/파편/품질 수치는 전부 SIM_TUNED_GAME_ONLY이며, 실제 무기의 설계나 측정 성능으로 제시하지 않는다. 전체 값과 선택 이유는 PREIMPLEMENTATION.md 및 spec.js 참조.

렌더는 기존 HTML의 CG 자산을 유지하며, DDG의 기존 각진 Mod4 생성기를 재사용했다. 별도 3D Warehouse 원본 파일을 추출/재배포하지 않는다.
