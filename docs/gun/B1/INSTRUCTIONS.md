## 1. CG-52 벙커힐 함포를 Mk 45 Mod 4로 교체

**근거 (공개 자료)**
- USNI Proceedings 2008-02: 벙커힐 순양함 현대화 때 Mk 45를 54구경에서 62구경 Mod 4로 교체했다.
- 2009년 시운전 기사: 5-inch/62 사격을 시험했다.
- 미 해군 Fact File: Mod 4 탑재함 목록에 CG 52–60이 포함되어 있다.
- 현재 코드의 근거(`CG52_2021_MK45_MOD2_PHOTO_CAPTION__5IN54_PUBLIC`)는 이 자료들과 충돌하므로 대체한다. 기존 근거 문자열은 보고서에 "대체됨"으로 기록한다.

**성능**
- CG의 두 마운트가 `MK45_MOD2_MK160_SURFACE_V1` 대신 **기존 `MK45_MOD4_MK160_SURFACE_V1`의 탄도·사통·마운트 성능**을 쓰게 한다. 포구속도 823 m/s, 사통 0.8–24 km.
- **CG 고유 값은 유지한다**: 설치 위치(`installation`/hardpoint), `stowBodyAzRad`, 사계 및 클리어런스, 마운트별 탄약고(마운트당 600발, 함 전체 1,200발. 공식 Fact File의 순양함 1,200발과 일치). 새 모듈 id가 필요하면 Mod 4 모듈을 펼쳐서 이 항목들만 덮어쓰는 방식으로 만든다.
- 기존 `MK45_MOD2_...` 모듈 정의는 삭제하지 않는다(다른 참조·회귀 보존).

**외형**
- CG의 기존 둥근 포탑 메시 2개를 DDG의 기존 **Mk 45 Mod 4 메시**(각진 쉴드 + 62구경 포신)로 교체한다. 같은 생성 함수를 재사용한다.
- 위치·선회·고각 연결은 CG 마운트 런타임을 그대로 따른다. 포구 위치(`trunnionOffsetM`, 노출 포신 길이)는 Mod 4 값으로 맞춘다. 탄 발사 원점과 3D 포구가 일치해야 한다.
- 원래 CG 포탑 메시는 숨기거나 빌드에서 제외한다. 3D Warehouse 원본 데이터는 재배포하지 않는 원칙을 유지한다.
- UI 표기 `Mk 45 Mod 2`를 `Mk 45 Mod 4`로 바꾼다.

## 2. 대공탄: Mk 187 HE-MFP + MK419 Mod 1 다기능 신관

**공개 자료**
- MK419 Mod 1은 Mk 187 Mod 0 고폭 다기능 탄의 기폭 장치다(SAM.gov 2016 공고).
- 모드는 공중 근접(AIR), 수상 근접(HOB), 자동, 전자시한(ET), 순발(PD)이며, AIR 모드에 해면 클러터 필터가 있다(NDIA 2012 Hendershot).
- AIR 모드 교전 범위로 약 1,400 ft–9,500 yd가 제시돼 있다(NDIA 2011 Ring, 고속정 대상 맥락).
- 신관은 함의 Mk 34 신관 장입기로 유도 방식으로 설정된다.

**탄종 추가**
- 두 모듈(DDG Mod 4, CG Mod 4)의 `ammunition`에 `MFF_127_SIM`(라벨 `127 HE-MFP`)을 추가한다.
  - 질량·지름·항력 모델·포구속도는 기존 127 HE와 같은 값을 쓴다.
  - 작약량은 `SIM_TUNED`이며, 기준은 Mk 80 HE-PD의 Comp B 3.7 kg(공개값)이다.
- 탄약고: **함 전체 탄약 수는 그대로** 두고, 그 안에서 MFF를 나눠 담는다. 분배 비율은 `SIM_TUNED`이고, 구현 전 보고에 현재 HE/SAP 수량과 제안 분배를 적는다.
- 탄종 전환은 기존 `selectAmmo`와 급탄 지연을 그대로 쓴다.

**신관 동작** (MFF 탄은 AIR 모드로 사격)
1. **장입**: 발사 시 사격해의 예측 비행시간(TOF)으로 시한을 설정한다. 전자시한은 보조 기능이다.
2. **안전 거리**: 포구에서 `armDistanceM` 전에는 작동하지 않는다. `SIM_TUNED`이며, 공개된 최소 교전거리 약 430 m를 기준으로 한다.
3. **근접 작동**: 매 스텝 탄 경로(선분)와 **실제 물리 공중 객체**(적 미사일·항공기·드론 등 기존 공중 엔티티) 사이의 최근접 거리를 계산한다. `proxRadiusM`(`SIM_TUNED`) 안에 들어오면 그 지점에서 폭발한다.
   - 신관은 물리 장치이므로 world 객체를 읽는 것이 맞다. 사격통제 쪽은 지금처럼 트랙만 쓴다.
   - 아군 요격탄도 근접 작동 대상이다(현실적 위험이므로 막지 않는다).
4. **해면 클러터**: 탄 고도가 낮을 때 해면 반사로 인한 오작동(조기 폭발)을 모델링한다. 클러터 필터가 있으므로 확률은 낮게 두되, 고도·입사각에 따라 달라지게 한다. 모든 파라미터는 `SIM_TUNED`이며, 시드 RNG를 쓴다.
5. **시한 보조**: 근접 작동이 없으면 설정 시한 + `etMarginS`(`SIM_TUNED`)에 공중 폭발한다.
6. 해면·지형·수상 표적 충돌은 기존 처리를 그대로 따른다.

**파편 판정**
- 폭발 시 **기존 SM-2/ESSM 파편 모델**(`_wip88FragmentationPk`, `_wip99FragmentArrivalGeometry`, `_wip99FragmentSpeedMps` 등)로 반경 내 공중 객체의 격추/손상을 판정한다. 5인치 탄두 파라미터 세트(파편 수·질량·속도·분포각)를 추가하고 값은 `SIM_TUNED`로 둔다.
- 결과 처리(격추, 손상, 잔해, 로그)는 SAM 격추와 **같은 경로**를 쓴다.
- **SM/ESSM 결과는 byte 동일해야 한다.** 파편 함수를 일반화해야 한다면 SM/ESSM 호출 경로의 산술 순서·RNG 소비를 바꾸지 않는 방법을 쓴다. 불가능하면 5인치 전용 경로를 별도로 만든다. 방식은 구현 전 보고에서 정한다.
- 시각 효과는 기존 `SHELL_AIRBURST` 이벤트를 재사용한다.

## 3. 공중 표적 사격해와 관문

- **공중 표적 사격해**: 기존 `solveTrack`은 수상 전용으로 두고, **공중 표적용 래퍼**를 추가한다. 래퍼는 트랙의 고도(`z`), 수직 속도, 3D 공분산을 `wip13b1SolveTrackState`에 넣는다. 핵심 계산기는 수정하지 않는다.
  - 마운트 고각 한계, `wip13b1GunClearance`, 지형 가림은 기존 함수로 검사한다.
  - 사격해 갱신 주기는 기존 `solutionRefreshIntervalS`를 쓴다.
- **공중 준비도/품질**: 수상 전용 `wip13b1SurfaceTrackReady`, `wip13b10SurfaceFireControlQuality`는 그대로 두고, 공중용을 새로 만든다.
  - 확정 트랙
  - 측정 나이 한계(`SIM_TUNED`)
  - 위치·속도 σ 한계(`SIM_TUNED`)
  - 예측 TOF 한계(`SIM_TUNED`)
  - 결과는 READY / DEGRADED / 불가 3단계로 낸다(MAP_D 태그 색과 연동).
- **권한**:
  - 수동 대공: 운용자 ID가 FRIEND/NEUTRAL이면 거부한다. UNKNOWN/HOSTILE/TRAINING_TARGET은 허용한다.
  - 자동 대공(§5): FRIEND/NEUTRAL 제외, 그리고 **미사일형 위협**(`classification==='ASM'` 또는 기존 `trackKinematicThreatCue(...).missileLike`)만 대상으로 하며, BDA상 격추·무해 판정된 트랙은 제외한다.
- 기존 수상 관문(`wip13b1SurfaceGunReleaseGate`, `wip13b1SurfaceReleasePolicy`)은 수정하지 않는다.

## 4. 수동 대공 사격 (지도)

- MAP_D 흐름을 확장한다. `5in`을 선택한 상태에서 **공중 트랙을 탭하면** 공중 사격해를 계산하고 태그에 표시한다.
  - 2줄째: TOF, 거리, 고도
  - 색: READY 초록 / DEGRADED 주황 / 불가 빨강 + 사유
- 현재 장전 탄이 MFF가 아니면 태그에 `대공탄 아님`을 주황으로 표시한다. 발사는 허용하며, 그 경우 기존 탄의 신관대로 동작한다.
- 발사 슬롯의 단발/연속 동작은 MAP_D와 같다.
- `5in` 탄종 메뉴: `HE / SAP / MFF`
- CG는 2문 자동 규칙(MAP_D)을 그대로 따른다.
- 링: `5in` 선택 시 기존 수상 링(0.8/24 km)에 더해, **자동 대공 범위 링**(§5의 `autoRangeM`)을 점선으로 표시한다. 라벨은 `대공 자동 9km (SIM)`.

## 5. 자동 대공 방어 (CIWS식 마운트 자율)

- 교전 모드(MAN/SEMI/AUTO)와 **무관하게** 마운트별로 동작하는 자율 방어다. SM/ESSM 교리 할당 로직과 연결하지 않는다.
- **스위치**: `5in` 메뉴에 `자동 대공 ON/OFF`를 추가한다.
  - 기본 ON
  - 함별 상태이며 게임 저장 스키마에는 추가하지 않는다. 불러오면 기본 ON
  - 하단 `5in` 칸에 작은 표식으로 상태를 표시한다(바 폭 불변).
- **표적 선정** (마운트별, 사격해 갱신 주기마다):
  1. §3 자동 권한을 통과한 트랙 중 수평거리가 `autoRangeM`(기본 9,000 m, `SIM_TUNED`, NDIA 2011 AIR 모드 상한 근거) 이내인 것
  2. 공중 사격해가 ok이고 해당 마운트 사계·클리어런스가 통과하는 것
  3. 그중 **도달 예상시간(TTC)이 가장 짧은 것**. 표적이 같으면 바꾸지 않는다(히스테리시스는 `SIM_TUNED`).
- **사격**: 선정되면 해당 마운트에 `command`를 내리고 연속 사격한다. 각 발마다 기존 사이클·급탄·사통 갱신을 그대로 지킨다. 표적이 소실·격추·범위 이탈하면 중지하고 다음 표적을 고른다.
- **탄종 자동 전환**: MFF가 장전돼 있지 않으면 `selectAmmo('MFF_127_SIM')`을 호출한다. 기존 급탄 지연이 그대로 적용된다. MFF가 소진되면 자동 대공은 중지하고 사유를 표시한다(HE로 대신 쏘지 않는다).
- **수동 우선**:
  - 지도에서 운용자가 그 마운트에 표적을 지정(수상·공중 모두)하고 사격 명령이 활성이면, 해당 마운트의 자동 대공은 보류한다.
  - 수동 명령이 끝나거나(`✕`, 무장 해제, 연속 중지, 단발 완료) 해제되면 자동 대공을 재개한다.
  - CG는 마운트별로 판단한다(한 문은 수동, 다른 문은 자동이 가능).
- **EMCON**: 별도 조건을 두지 않는다. 트랙이 끊기면 자연히 표적이 없어진다.
- 자동 명령은 fixed tick에서만 실행한다. 렌더/UI 갱신에서 실행하지 않는다.
- **다른 함정(NPC/multiship)**: 이번에는 자함만 적용한다. 다른 함정의 함포 AI는 바꾸지 않는다.

## 6. 보존 조건

- 표적 truth를 **사격통제·UI·자동 선정**에서 읽지 않는다(트랙만 사용). 신관 근접 판정만 물리 world를 읽는다.
- 비행 지문 281개, 사거리표 120행 byte 동일. SM/ESSM/SM-6/하푼/CIWS 결과 byte 동일.
- **회귀 해시 규칙**:
  - **자동 대공 OFF**로 실행한 기존 회귀(도메인, 종료기 300발, 자연 WebGL 8발, world120 무표적·전투, raid 기준)는 MAP_E와 **동일**해야 한다. 단, CG 함포가 개입하는 항목은 Mod 4 교체로 달라질 수 있으며, 차이는 원인별로 보고한다. **승인된 raid 기대값은 임의로 갱신하지 않는다.** 달라지면 보고 후 사용자 승인을 받는다.
  - 자동 대공 ON(기본값) 실행 결과는 별도 증거로 제출한다.
- 저장 스키마 변경 0. 기존 저장을 불러와도 동작해야 한다(MFF 수량이 없는 옛 저장은 기본 분배로 채우는 규칙을 보고한다).
