# 공중 plot 원점 계약 누락 — Phase 0 발견, 제품 미수정

## 확인한 경로

기준 GUN_B1의 실제 함수에서 아래 경로가 확인됐다.

1. `spySurfaceOriginWip13B9(task)`가 현재 SPY 안테나 원점을 구한다.
2. `spyCollectUnifiedEchoPlotsWip13B13()`가 그 원점에서 RF 거리·방위·고각을 측정한다.
   공통 RF 에코의 Cartesian x/y/z는 원점을 더해 올바르게 복원한다.
3. `shipboardRadarEchoToAirPlotWip13B13()`는 그 극좌표 측정치를 그대로 내보내면서
   sensorXWorld/sensorYWorld/sensorZM/sensor velocity 메타데이터를 포함하지 않는다.
4. `updateSensorTrackMeasurement()`는 이 plot을 `trackEkfUpdateRadar()`로 전달한다.
5. `trackRadarPrediction()`은 메타데이터가 없으면 함 중심과 OWN_ALT_M을 원점으로
   사용한다. 실제 측정은 안테나 기준인데 예측은 함 중심 기준이 된다.

같은 공중 plot을 사용하는 NPC 관측 어댑터는 이미 receiver 원점을 명시적으로
덧붙인다. 자체 SPY의 공중 경로에는 그 덧붙임이 없다. 수상 경로는 별도 원점
계약을 사용한다. SPQ AIR도 공통 변환기를 사용하므로 후속 수정 시 끝까지 전달되는지
함께 감사해야 한다.

## 잡음 없는 private 검증

실제 게임의 plot 변환기와 EKF 예측 함수를 그대로 실행했다. DDG/CG × SPY 4면
× 방위 0/90° =16개 합성 입력이다. 새 센서 함수나 필터를 구현하지 않았고,
월드 트랙에 넣지 않은 private 상태에만 연산했다.

안테나와 함 중심 사이의 벡터를 L, 합성 입력 위치를 T라 하면, 원점이 누락된
소비자가 극좌표 측정과 정확히 맞는다고 판단하는 위치는 **T−L**이다.
원점을 명시한 private 측정은 **T**에서 정확히 맞는다. 16개 모두 확인했다.
알려진 own-sensor 원점만 보존한 private 자료는 수치 조정이나 truth 보정이 아니다.
진단 연산 전후 RNG와 실제 월드 트랙 수의 변화도 0이었다.

F2 면의 합성 표적 고도 12m 입력에서 다음 값이 나왔다. 이는 보정용 상수가
아니라 해당 시각의 기존 모델에서 읽은 원점 차이다.

| 함정 | 안테나−함 중심 X/Y/Z(m) | 누락 소비자가 맞다고 보는 Z | legacy 트랙 Z |
|---|---|---:|---:|
| DDG | 31.0121 / 6.2547 / 13.8398 | −1.8398m | 0m |
| CG | 27.9179 / 7.2656 / 16.2969 | −4.2969m | 0m |

`trackSyncLegacyFromEkf()`는 negative KF altitude를 0으로 제한하므로 함포가 읽는
고도가 0m가 되는 현상도 설명된다. 이 clamp를 풀어 음수 고도를 그대로 쏘게 하는
방식은 원점 계약 복구가 아니다.

자연 G7 발사 로그에도 표적 위치의 거의 일정한 X 편향이 보인다. 방위 0°에서는
주로 사격선 방향 오차가 되고, 90°에서는 측방 오차가 되어 25m 근접 반경과
직접 부딪힌다. 전체 30회 분포와 A–D 비교는 PHASE0.md에 별도로 싣는다.

## 승인 전 적용하지 않는 이유와 최소 수정안

지시서 §0은 센서를 변경하지 말라고 정한다. 이 발견은 단순한 함포 상수 문제가
아니므로, Phase 1의 기존 §4 대신 별도 선행 수정으로 허용할지 사용자의 결정이 필요하다.
현재 HTML·센서·판정·저장 스키마는 바꾸지 않았다.

권고하는 최소 변경은 실제 극좌표 측정에 사용한 **동일 receiver 원점/속도**를
관측 메타데이터로 보존하고 association과 EKF까지 전달하는 것이다.
기존 NPC 어댑터와 같은 계약을 자체 SPY에도 적용하는 방향이다. 공통 변환기를
확장할지, receiver를 이미 아는 수집기에서 명시할지는 호출부 전체 감사 후 정한다.
RF Pd·잡음·RCS·빔·KF 이득은 변경하지 않는다.

- 고정 +30m 보정, 임의 고도 대입, 표적 truth를 읽는 사격해 보정은 하지 않는다.
- 자연 관측을 쓰는 SAM 결과도 달라질 수 있다. “기존 SAM 결과 byte 동일”이라는
  보존 조건과 함께 해결해야 하므로 자동으로 범위를 넓히지 않는다.
- 수정한다면 자체 레이더/보조 레이더/NPC/오프보드 원점 계약을 구별하고,
  잡음 없는 왕복 검증과 자연 탐지 회귀를 먼저 수행한다.
- 원점 수정 후 함포 측정은 현재 Phase 0과 다른 입력 조건이다. 별도 버전과
  결과로 기록하고, 현재 측정을 수정 후 결과인 것처럼 재사용하지 않는다.
