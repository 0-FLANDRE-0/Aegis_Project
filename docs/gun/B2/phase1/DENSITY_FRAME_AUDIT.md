# 파편 밀도 좌표계 감사와 수정

초기 내부 후보(물리v1, HTML929523d6…)의 추가 감사에서, 밀도 면적에 **관성계 띠 입체각**과 **탄과 함께 이동하는 Gurney 구의 반경**을 곱한 혼합을 발견했다. 두 좌표계의 면적을 일관되게 평가해야 한다.

몸체 밀도 수정v2(HTML97089f4b…)는 균일한 몸체 환형 분사를 가정한다. 기존 파편 수N, Gurney 속도vf, 파편 반폭20°, 표적 상대운동은 유지한다.

- 파편 도달시간: |r+(v_target−v_shell)t|²=(vf·t)²의 최소 양의 해.
- 몸체 반경: R=vf·t, 기존 근거리 수치 하한은 유지.
- 몸체 입체각: Ω=2π[cos(90°−20°)−cos(90°+20°)]=4πsin20°.
- 밀도 면적: A=R²Ω, 독립 파편 밀도=N/A.
- 몸체 방향90°±20° membership을 통과한 경우에만 기존 관통·살상 계산을 적용한다.
- 탄 속도를 합친 관성계 경계각은 진단값으로 보존한다. 밀도 분모에 섞지 않는다.

이 수정은 파편 수/질량·폭약/Gurney 계수·피해 RNG/Pk 원본 함수를 조정하지 않는다. 기존 gunB1FragmentationPk, _wip88FragmentationPk, applyInterceptResult는 byte 동일이다. 새5인치 복사본의 기하 정규화만 바꾼다. Pk가 바뀌므로v1의 사격 성과를 최종 물리v2의 측정값으로 사용하지 않는다.

300/800/1500m/s 운반 속도에서 같은 몸체 반경·분사각을 구성해 면적과 N=밀도×면적을 검증했다. 같은 좌표계의 면적은 운반 속도가 바뀌어도 같다. 기존16 물리 검증에 이2항목을 더한18항목을 통과했다.

## 거리 밖 빠른 거절

구 교차 결과가 false일 때 기존 caller는 나머지 구간을 읽지 않고 즉시 건너뛴다. 구 교차를 먼저 계산해 같은 false를 반환하도록 했다. 해당 경우 원뿔 경계 계산을 생략한다. 구 교차가 true인 경우 기존과 같은 경계/적분 구간을 유지한다. 12,000조건에서 caller가 사용하는 inSphere/endInside 및 사용되는 intervals가 동일했고 전역 RNG 소비0이었다. 파라미터·탐지 시점·처리 지연을 바꾸지 않는다.

## 보존과 재측정

정적 감사에서v1→v2 변화는 gunB2FuzeIntervals, gunB2FragmentField, gunB2FragmentationPk 세 함수뿐이었다. 나머지 main source는 byte 동일이다. 281보호 지문·ENV_D120행·RF/EKF·기존피해 함수도 동일이다. 전체 승인 변경을 되돌린 main source가 원본4c519와 byte 동일임을 별도로 검사한다.

v1의1440거리 시도와 미완료G7 행렬, 원시 진단/소스/diff는 density-frame-v1 경로에 보존한다. 최종 거리1440시도와 G7 960회는v2에서 새로 실행한다. v1 산포/정합/대칭 창 검증은 해당 함수/상수 변경이 없고, OFF 경로에서는 세 변경 함수가 호출되지 않으므로 별도 source guard 아래 기존 결과와 비교할 수 있다. 최종v2의 실제 native 함수 계측·OFF/ON쌍·물리 검증은 다시 실행한다.

SAM 직접진단과 AutoAA OFF 회귀의 사용 함수는 세 변경 함수와 분리되어 있다. 원시 파일의 실제 HTML SHA를 그대로 남기고, 보호 경로 동등성에 따른 재사용을 명시한다. 오래된 사격 성과나 파일SHA를 새 버전 측정으로 덮어쓰지 않는다. 새 기대값을 승인하거나 허용 오차를 바꾸지 않는다.
