## 산포 역산

무풍, MSL0 착탄 평면, native 모듈/탄약/가속도, 원점 높이10.92m다. 원점 속도는0이다. 공칭 native 착탄은16458.99633097502m다. 사거리 감도는 다음과 같다.

- MV 비율에 대한 감도: 20533.56348516718m / fraction
- 고각에 대한 감도: 34140.579725608404m / rad
- σ_MV =49.5·sqrt(.8)/감도_MV
- σ_el =49.5·sqrt(.2)/감도_el, mrad로 환산

초기 .0015/.10mrad 400발에서는 사거리σ31.696m였고, 역산 뒤 별도400발은 **50.84974998413663m**였다. 편향σ **3.481998603106081m**, 평균16457.992555m다. native updater와 동일 경계의 착탄 차이0m, 전역RNG 소비0, 같은serial/seed 반복동일이다. 탄속·항력·질량·공칭값을 바꾸지 않았다.

## 신관 시간 적분

신호 =기존RCS/기준RCS ×(12.5/r)^4×cos²(환형 패턴 안 정규화 각·π/2)다. r 최소.5m는 영점 특이점의 수치 보호이며 명중률에 맞춘 값이 아니다. 원뿔/구 교차 구간을 먼저 나누고5점 Gauss 적분, 최초 budget 도달 시점은18회 이분 탐색한다. 수치 epsilon은 기하 경계/분모 보호용이다.

통과당 한 uniform U로 budget=−ln(1−U)·.003/−ln(1−.9)를 만든다. 빔 안 유효 신호만 초 단위로 누적한다.25m 범위 안 빔 공백에서는 유지, 범위 이탈하면 초기화한다. 재진입은 다음pass의budget이다. 탐지 후에도 기존 충돌/해면/ET/클러터와의 선후 경쟁을 그대로 한다. 첫 탐지+2ms가 실제 기폭 후보이며,60Hz마다 Pd를 재추첨하지 않는다.

## 파편 기하

기폭점→표적의 상대벡터 r, 표적−탄 속도 w, 기존 Gurney 속도 vf를 사용한다. |r+w·t|²=(vf·t)²의 양의 최소해가 파편 도달시간이다. 그 방향이 몸체90°±20°에 있을 때만 새5인치 복사본이 기존 밀도/관통/살상 계수로 Pk를 계산한다. 관성계 띠 경계는 탄 속도+Gurney 속도를 합성해서 정한다. 밀도에 쓰는 반경은 v_f·t의 실제 상대 파편 반경이다. 예전 CPA 잔차거리와 같다고 표현하지 않는다. 원본 gunB1FragmentationPk 및 _wip88FragmentationPk는 byte 동일하다.

정확히 r=0인 인공 기폭점에는 양의 파편 도달시간/방향이 정의되지 않아0이다. 이것을 일반적인 발사·요격 검증이나 강제 명중으로 바꾸지 않는다. 기존 exact-overlap 합성 시험이 달라지면 그대로 실패/원인을 기록한다.

## 근거리 결과 해석

native 계측 seed592001 정면 사례에서1/5km의 도달 몸체각은 각각 약135.34°로 띠 밖이고,9km는 약105.10°로 띠 안이었다. 탐지→기폭은 모두 정확히2ms였다. 기폭 시 탄속은 약779.35/621.54/490.35m/s다. 관성 파편 띠는 탄속·표적 상대속도에 따라 바뀌지만 탐지 환형50~90°와 처리 지연은 고정이다. 작은 통과 거리에서는 탐지 지연과 파편 비행 사이에 표적이 지나갈 수 있다. 점 반사체 가정과 이 시간/기하 조합을 포함한 결과다.

그래서 현재1~9km 곡선은 단조 감소가 아니다. 숫자를 바꿔 원하는 격추율에 맞추지 않았다. **≥9km는 외측 .05 하강 지점을 아직 못 찾았다는 뜻이며,9km 안에서 모두 잘 맞는다는 뜻이 아니다.** CG전방1km는 기존 MOUNT_OCCLUDED로40시도 모두 미발사였다. 미발사를 실제 비명중40발로 세지 않는다. 이 모형의 근거리 효과와 전체 전투 결과 차이는 PR 검토 사항이다.
