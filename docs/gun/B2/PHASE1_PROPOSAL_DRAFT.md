# Phase 1 설계 초안 — 미구현, Phase 0 결과 검토 후 승인 대상

이 문서의 새 수치는 모두 **SIM_TUNED 초안**이다. 실제 Mk419 탐지 성능으로
주장하지 않는다. 표적 명중률이나 G7 격추율을 맞춰 역산하지 않는다.
Phase 0 제품에는 적용하지 않았다. 최종 제안의 우선순위는 PHASE0.md에서 정한다.

**추가 범위 결정:** Phase 0에서 공중 plot 원점 누락을 확인했다.
`ORIGIN_CONTRACT_FINDING.md`의 선행 수정안을 먼저 검토해야 한다.
센서 변경 금지와 충돌하므로 다른 구현 승인에 자동으로 포함하지 않는다.

## 사격해와 포인팅

발사 직전의 정합이 필요하다고 확인되면 현재 관측 트랙·현재 trunnion으로
기존 continuation solver를 호출하고, 새 해를 기준으로 포인팅·권한·클리어런스를
다시 검사한다. 대기 중인 단발/연속 사격의 표적을 바꾸거나 판정을 우회하지 않는다.
새 해와 포신이 맞지 않으면 발사를 보류한다. 이 시점에 truth로 해를 보정하지 않는다.

진단 B는 실제 발사 횟수보다 재계산 시도 수가 많을 수 있다. 갱신 뒤 아직 포신이
맞지 않아 재시도하기 때문이다. 실제 비용은 PHASE0.md에 보고하고, 제품 구현에서는
불필요한 동일 입력 재계산을 캐시하되 오래된 해로 발사하지 않도록 설계한다.
프레임마다 전 표적을 새로 푸는 방식은 쓰지 않는다.

수상 추가 진단은 5/10/15km, 관측 속도 10m/s, 1초 시차에서 native 탄도 적분으로
오차를 측정했다. 수상까지 같은 정합을 적용할지 PHASE0.md에 따로 제안한다.
기존 수상 식별·권한·FCQ·사계 판정은 유지한다.

공중 포인팅은 25m 신관 반경의 일부를 포신 오차 예산으로 쓰는 대칭 창으로
분리한다. 관측 불확실성과 포신 오차는 구별하고, 창 변경으로 관측 오차를
없앤 것처럼 처리하지 않는다. 기존 수상 `wip13b6GunPointingAssessment`는 보존한다.
현행 AIR의 실제 cross limit는 불확실성 차감 뒤 1.5m floor까지 줄어든다.
따라서 아래 6.25m 초안을 “현행보다 항상 엄격한 창”이라고 해석하면 안 된다.
불확실성 차감과 포신 정렬 예산의 결합 방식을 승인 전에 명시해야 하며,
이번 진단에는 새 창을 적용하지 않았다.

## 산포

16,459m에서 사거리 σ 44~55m라는 **지시서 지정 앵커**만 보정에 사용한다.
200발 이상을 실제 point-mass 경로로 적분한다. native 유한차분 민감도로 포구속도와
고각의 분산을 배분하고 포구속도가 주성분이 되게 한다. 명중률은 보정 입력이 아니다.
선회 산포는 공개 앵커가 없으므로 별도 SIM_TUNED로 둔다.

공칭 포구속도 823m/s는 유지한다. 지시서가 인용한 Mk67의 808m/s와는 +15m/s
(약 +1.86%) 차이다. 이번 작업에서 공칭값을 맞추지 않는다.
DTIC 원문 URL은 `https://apps.dtic.mil/sti/pdfs/ADA331645.pdf`이며 이번 환경의
웹 열람은 실패했다. 44~55m를 독립 재확인한 공개 수치라고 과장하지 않고,
사용자가 지정한 게임 산포 보정 계약값으로 기록한다.

발 serial·SIM_SEED_BASE에서 만든 독립 스트림으로 속도/고각/선회 편차를 만든다.
`simRandom()`과 기존 해면 클러터 budget의 스트림은 건드리지 않는다.
모든 B2 플래그 OFF에서는 원래 spawn/신관 경로로 돌아가야 한다.

## 5인치 전용 신관

탄 축 기준 전방 경사 환형 탐지 패턴을 swept 상대운동에 적용한다. 최초 유효 탐지
시각을 구하고 처리 지연 뒤 기폭한다. 고정 틱의 끝점에만 의존하지 않게 한다.
안전거리·ET·기존 클러터 hazard와 budget은 그대로 유지한다.

통과마다 독립 난수는 하나만 생성한다. 같은 통과에서 매 60Hz 틱마다 새 Pd 추첨을
하지 않는다. 한 방법은 그 한 난수로 통과의 신호 누적 임계값을 정하고,
RCS/거리⁴/안테나 이득에 따른 누적 신호가 그 값을 넘는 최초 시점을 찾는 것이다.
첫 약한 신호에서 실패했다고 뒤의 강한 신호까지 영구 미탐 처리하지 않는다.
시간 간격을 바꿔도 같은 연속 입력에서 탐지 경향이 유지되는지 검증한다.

RCS는 실제 물리 신관 경계에서 기존 `getASMRcs`/프로파일을 사용한다. 이를
사격통제나 UI가 읽게 하지 않는다. **이번 Pd 제안은 5인치 전용**이며 기존 SAM의
결정론적 신호 탐지와 WIP99 파라미터는 변경하지 않는다.

## 파편

기존 5인치 private Pk 복사본에 도달 방향의 띠 안 판정을 추가한다. 탄 속도,
Gurney 속도, 표적 상대운동과 기존 파편 도달 시간을 반영한다. 띠 밖이면 Pk 0으로
하고, 띠 축소와 판정을 한 번에 적용한다. 띠 폭만 줄이는 중간 버전은 출하하지 않는다.
원래 `_wip88FragmentationPk`와 SAM/ESSM 경로는 byte 동일하게 보존한다.

값과 근거를 먼저 고쳐 보고하며, 격추율을 올리기 위해 임의 조정하지 않는다.

기존 430m 무장거리, ET +0.2s, 해면 클러터 값, 파편 수/질량/Gurney 값,
공칭 포구속도, 자동 교전 9km는 변경하지 않는다. 단발 Pk 거리 곡선을 실제
새 모델로 측정한 후에만 유효 링 값을 제안한다. 지도에는 유효 링과 자동 교전
9km를 서로 다른 점선·라벨로 표현하는 안을 사용자에게 제시한다.
