# AIR_ORIGIN_A 병합 후 GUN_B2 재진단

최신 main은 PR #60 병합 cce180255e0f76b804a2ae6a3b6078aec2f9dea8이다.
gun-b2는 이전 b159ff2fb0de38b23134e4693834f017fcb11464의 두 문서 커밋을
이 main 위로 rebase했다. 이 단계에서는 게임을 바꾸지 않는다.

시험 입력은 결과를 보기 전에 아래와 같이 고정했다.

- DDG/CG × 방위 0°/90° × 시드 419010…419024 = 60회.
- 각 회차 Kh-35U 1기, AutoAA ON, BASE(진단 A/B/C/D OFF).
- 이전 Phase0와 같은 새 게임 페이지/문맥, HTTP 전달, native 전체 fixed tick.
- G7의 50초 상한/표적 종료 조건과 기존 CIWS를 그대로 사용한다.
- 비교군은 기존 Phase0의 같은 60개 입력으로 한정한다. 실패 표본 제외 없음.

제품은 병합된 AIR_ORIGIN_A HTML SHA-256
4c5191753025406697520c63afcc97c116a83c4b6b924a4b605b49233c697eeb이다.
원래 build_fixture.py를 바꾸지 않고, 메모리 사본에서 입력 파일/해시 검사
한 줄만 명시적으로 바꿔 기존 계측을 실제 최신 게임 함수에 적용한다.
과거 C9 HTML·도구·2,400회 결과는 보존한다. B2 새 기능은 넣지 않는다.

실행 중 RF 원점 전달/KF/native spawn 함수 해시를 수집한다. 별도 native
4조건과 계측 결과를 비교해 로거가 결과·RNG·최종 상태를 바꾸지 않는지
확인한다. 90° 두 조건은 같은 시드로 한 번 더 실행해 결정성도 확인한다.
이 추가 6회는 주 행렬 60회와 구별한다.

관측 오차·CPA/arrival·ET·검열·해 나이·초기 선회는 이전 분석 규약과 같다.
truth는 사후 진단에만 쓰며 사격통제에 되먹이지 않는다. 이전에 승인한
기대값을 재갱신하거나 허용 오차를 넓히지 않는다.

## 후속 악화 사례 확인

60회 결과에서 DDG90 seed419023의 HP 저하 1건을 확인해, 같은 입력의 C9 native/AIR native 2회를 추가했다. 이 2회는 주 행렬과 통계에 합산하지 않는다. 피해 RNG 호출은 원래 함수에 한 번만 맡기고 생성된 값을 읽어 기록했다. 두 실행 모두 원래 기록의 결과·RNG·최종 상태와 일치했다.
