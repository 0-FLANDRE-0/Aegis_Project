# Aegis_Project 작업 아카이브

앞으로 할 일, 사용자 결정, 설계 메모, 작업 방식, 지시서 원문을 레포 안 한 곳에 모아두는 폴더다.
새 채팅의 리뷰 AI와 작업 AI는 **이 폴더부터 읽는다.**

## 우선순위

레포 코드·보고서 > 이 아카이브 > 대화 기억

아카이브 내용이 레포 실제 내용과 다르면 레포가 맞다. 아카이브를 고치고, 다른 점은 사용자에게 알린다.

## 파일

| 파일 | 내용 |
|---|---|
| `STATUS.md` | 지금 어디까지 왔나 (인계서 역할) |
| `ROADMAP.md` | 앞으로 할 작업 순서 |
| `BACKLOG.md` | 다음 지시서에 넣을 것, 별도 조사, 미룬 일, 기존 부채 |
| `DECISIONS.md` | 사용자 결정 기록 (날짜순) |
| `DESIGN_NOTES.md` | 설계 메모 (아직 지시서가 안 된 생각) |
| `REVIEWER_PLAYBOOK.md` | 리뷰 AI 작업 방식 |
| `directives/` | 지시서 원문 |
| `history/` | 지난 인계서 등 기록용 문서 |

## 갱신 규칙

- `DECISIONS.md`는 **추가만** 한다. 결정을 뒤집을 때도 지우지 않고 새 날짜 줄로 적는다.
- 지시서 원문은 사용자가 작업 AI에게 넘긴 판을 그대로 `directives/`에 둔다.
- 작업 AI는 지시서에 적힌 경우에만 `STATUS.md`·`BACKLOG.md`를 갱신한다. 그 밖의 아카이브 파일은 리뷰 AI나 사용자가 고친다.
- 이 레포는 공개 레포다. 비공개로 둘 내용은 여기에 쓰지 않는다.
