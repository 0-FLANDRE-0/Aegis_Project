# VP_A 구현 전 기준 정리

기준: SOV_A `c7d498d063010385b1aa2172049c4dd248f96ec1`, 원본 SHA-256 `1e2125e49ae0720d45f2457474753ed948324241aecf69120f5c7694ea733b28`.

사용자에게 구현 전에 보고한 차이와 처리:

1. 옛 `mapZoom 0.08–6`은 px/world이므로 창마다 다른 거리 한계다. 일관된 단일 km 한계가 존재하지 않는다. 요청한 일곱 시험 크기의 옛 거리 범위 합집합을 고정 한계로 채택했다. 옛 짧은 변 390–1080px, 3.8 world/km에서 **7.184210526–1492.105263158km**. 기존 15/40/120/300km 단계 모두 유지한다. 새 기준의 짧은 변은 dock를 제외한 보이는 영역이다.
2. `PerspectiveCamera(38)`은 고정 소형 창이 아니라 가변 크기의 미사일 카탈로그다. 동일한 짧은 변/투영 중심 규칙을 적용하되, 해당 뷰의 의도된 기준 **38°**를 보존한다. 주 전술 3D는 52°다.
3. 검수 C의 자함은 센서 트랙/공격 선택 대상이 아니다. 기존 ARM 조작도 지도 탭으로 커서를 옮기고 LOCK 버튼으로 표시 트랙을 지정한다. 이 정책을 우선하여 **자함 탭의 커서 좌표**, **실제 표적 탭→LOCK**, **하푼 경로 탭**을 분리 검증한다. 자함 공격 트랙이나 탭 즉시 LOCK을 새로 도입하지 않는다.

검수 정의: D/E의 자함 투영 기준점은 기존 기본 카메라의 함 로컬 `(0,11,0)` 조준점이다. 기존 yaw/pitch/distance/targetY를 바꾸지 않는다. 선수·함미 끝점은 별도로 투영하여 길이 비율과 화면 내 포함 여부를 검사한다. 원근 투영된 외곽 사각형의 중간점과 카메라 조준점은 다른 개념이다.

소브레멘니 자함화와 공용 파랑 응답은 조사만 한다. 물리·센서·교전·저장 계약과 기존 NPC 제한은 이번 변경의 대상이 아니다. 카메라 팬은 작전 저장 대상이 아니며 정규화 값으로 세션 중에만 소유한다.
