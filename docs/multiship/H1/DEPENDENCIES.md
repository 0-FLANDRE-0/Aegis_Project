# H1 이후

1. **H2 기동 utility**: measured 위협 방위·접근/CPA와 자기 속도·타율·무장 사각으로 침로 유지/선회/속력 후보를 비교한다. 실제 적 좌표를 읽지 않는다. NAV/FLEET 수동 항법이 우선하며 AI 재개는 명시 조작으로 한다. 해역/지형 회피는 native terrain/contact와 일관된 자기 항법 경계에서 검증한다.
2. **H3 대수상 공격**: 현지 SURFACE 관측·식별/ROE·아군 보호와 별도 동의로 하푼 발사 계획을 연결한다. 현재 Harpoon·대수상 SAM MANUAL-only를 임의 해제하지 않는다. INS/ARH와 DL0를 유지한다.
3. **팀 전술**: 개별 기동/공격이 안정된 뒤 전파된 measured 정보와 요청/동의로 역할·팀 기동·손상함 보호를 확장한다. peer private FCS/실제 적 위치·생존으로 명령하지 않는다.
4. 헬기의 외부 센서 포트와 G measured network로 지평선 밖 탐지를 붙일 수 있다. 헬기 운용·CEC급 원격 사통은 별도 범위다. 미래 토마호크는 사용자가 지정한 RGM-109E Block Va다.
