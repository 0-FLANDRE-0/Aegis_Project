# G 다음 단계

FLEET의 owner별 수동 조종·교전과 아군의 측정 공유·CIC 정정·레이더 EMCON·한시적 SAM 방어 분담을 먼저 확보했다. 다음 H는 이 경계 위에 **현지 관측 기반 전술 AI**를 얹는다.

1. 함정별 위협·탄약·사통/장비 손상·속도/조종 가능 상태를 요약하고 방어 태세/기동 의도를 독립 저장한다. 적 실제 위치/생존 상태 또는 다른 함정의 private 사통을 판단 입력으로 사용하지 않는다.
2. 기존 AUTO와 SAM/근접방어를 하위 실행기로 유지한다. 현지 위협 우선순위, 탄약 절약/살보, 링크 단절·손상 시 보수적 개별 운용을 검증한다.
3. 측정 방위/위협 접근, 무장 사각과 기동 능력에 따른 회피·방위 유지·속도 명령을 기존 owner 항법 포트에 연결한다. 적 함정을 배치했다는 이유로 탐지되지 않은 적 위치를 알게 하지 않는다.
4. 공격은 별도 현지 수상 관측·ROE/보호 식별·Harpoon 발사 승인 경계에서 연결한다. 상대 faction/truth ID로 자동 HOSTILE을 주입하지 않는다. 대수상 SAM의 기존 MANUAL-only 정책은 유지한다.
5. 팀 기동/역할·피해 함정 보호는 개별 판단이 안정된 뒤 추가한다. 통신 장애·오연관·공동 침묵 중에도 blind fire가 없어야 한다.

지평선 밖 센서가 필요하면 기존 외부 관측 포트와 G 측정 전송을 이용해 헬기의 모델/비행/센서/운용을 연결한다. 원격 관측만으로 무장을 사격하는 CEC급 기능은 별도 검증 범위다. 추후 토마호크 대상은 사용자가 지정한 **RGM-109E Block Va Maritime Strike Tomahawk**다.
