## 2. C1 조사

1. **사각 정량화**: 두 문 각각의 사각 경계를 0.1° 해상도로 구한다(고각 −1°, 0°, +2°, +5°).
   - 광선 시작점은 (a) 현재 코드의 회전축, (b) 실제 포구(`muzzleOffsetLocalM`, 약 1.65 m 앞) 두 가지로 비교한다.
   - 근접 포신 회전(2 m) 판정과 원거리(300 m) 판정을 따로 기록한다.
2. **방위 민감도**: CG, Kh-35U 1기, AutoAA OFF에서 위협 방위 0° / ±1° / ±2° / ±5° / ±10° × 10시드로 CIWS 사격 여부, 탄 소모, 피격을 측정한다.
3. **실함 비교**: 타이콘데로가급(CG-52 이후 개장형) 팰렁스 위치와 상부구조물 폭을 공개 자료로 확인한다(미 해군 사진, NavSource, 공개 도면 등).
   - 모델 좌표(x≈3 m 중앙부, y=±6.06 m, z≈18 m)가 실함과 맞는지 판단한다.
   - 실함에도 정면 사각이 있는지 공개 자료로 확인되면 출처를 단다. 확인되지 않으면 "미확인"으로 둔다.
4. **기동 대응 현황**: 현재 자함·AI에 위협 방향을 보고 사각을 여는 기동(arc-opening)이 있는지 코드에서 확인한다. 미병합 PR #52~#55(multiship-tactical H1~H4)에 관련 로직이 있는지도 확인만 한다.

## 3. D1 조사

DDG-119, Kh-35U 1기, 90°, AutoAA OFF, 시드 419010~419039 30회를 계측 재실행한다(GUN_B2 Phase 1과 같은 입력).

**회차별 타임라인 로그**
- 위협 트랙: 최초 탐지, 확정, 거리별 시각
- 교전: SM/ESSM/SeaRAM/CIWS 각각의 큐, 첫 발사·사격 시각, 발수, 결과
- CIWS 내부 상태:
  - 자체 센서 탐색/추적 전환 시각
  - 사계 판정 결과와 막힌 사유(구조물·고각·사계 끝)
  - 사격 중단 사유
  - SeaRAM/팰렁스 간 우선순위
- 피격 시: 명중 위치(구획/모듈), 탄두 폭발·파편·화재·유폭(VLS·탄약고 등)·침수별 피해 분해, HP 시계열, HP 0이 된 직접 원인

**분석**
- CIWS 탄 소모가 적은 이유를 분류한다(앞단 격추로 미교전 / 사계 차단 / 추적 실패 / 우선순위 등). 회차 수를 센다.
- **HP 0 4회**: Kh-35U 1발(공개 탄두 약 145 kg)로 HP 0에 도달하는 경로를 분해한다.
  - 피해 모델이 의도대로 동작한 결과인지(예: VLS·탄약고 유폭), 계산 오류나 이중 계상인지 판정한다.
  - 같은 회차를 CG로 바꾼 대조 1회와, 명중점이 다른 일반 피격 회차와 비교한다.
