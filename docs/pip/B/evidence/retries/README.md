# 합계에서 제외한 시도

- 최초 GPU 기반 MAP3D·ISAR UI·SOV visual: Playwright30초 두 프레임 안정 대기 만료. 실제 버튼좌표8프레임 동일, 프레임8–9초.
- 최종 후보 첫 실제PiP 전환 재검사: #pipSwapA 안정 대기30초 만료. 같은 입력/동작/판정을 유지하고 headless default timeout120초로 재검사하여12건 모두 통과. 강제 클릭은 사용하지 않았다.
- 원래90프레임×4 부가 벤치는 대규모 ENV_A와 동시에 실행되어 장시간 소요해 중단. 기능 검사를 유지한 최종12프레임×4 측정을 별도 수행했다. 재현 스크립트의 기본90은 유지한다.
- 초기 native input 롱프레스2건은 부하 조건에서 시간 초과했으며 원래 assertion/이벤트로 재실행해98건 통과.
- 초기 PiP resize handle2건은 실제 캔버스 가림 문제여서 CSS z-index를 수정했다. 최종103건 통과. 초기 항적1.5px 측정3건은 기존 density helper가1.08–1.22px를 내어 실패했다. 화면1.5px 변환으로 바꾸고 최종10건 통과.

최종 pass 영수증과 실패/중단 시도를 구분한다. 이 파일은 실패를 pass로 변환하는 대체 영수증이 아니다.
