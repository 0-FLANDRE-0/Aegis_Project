## Native replay preparation (no browser before explicit root GO)

The three R1 controllers are copied to this sibling directory. Adapter diffs and
source SHA receipts are in `NATIVE_CONTROLLER_ADAPTER.json` and `evidence/`.
Only output-root/default STABLE_B filename plumbing, explicit R1 helper paths,
and read-only source-pin checks are added. Actual fixture source, game checks,
expected outcomes and tolerances stay unchanged.

- `run_native_policy.py`: representative original19, new native23 and actual
  matrix/epoch/callback18; SHADOW first, then ACTIVE after root authorizes it.
- `run_original_native.py`: all original23 groups (OFF84/ON90) plus cohort14 in
  eight fair fresh contexts; original cohort still internally forces diagnostics
  ON and is labelled accordingly.
- `run_native_saturation.py`: old B/SHADOW/ACTIVE actual-NIS13/16 clear grids and
  equal13 negative control. This does not substitute for captured/natural13 combat.

`NATIVE_TEST_INPUT_PINS.json` pins R1 controllers/helpers and canonical B/A test
support. `controller_pins.py` checks their bytes before any copied controller can
launch a browser. Products do not exist yet at preparation time; actual new HTML
hashes must be supplied explicitly. Current defaults name STABLE_B and do not
permit reuse of R1 HTML under a new label.

Raw failures, fixture-premise failures, full-state deltas and original strict
assertions are retained. Snapshot/ENV/private-RNG purity is rechecked using the
actual product. No tactical identity, truth reference or look-ahead filter update
is added by tests. No browser is run during this preparation phase.
