# 통계 표본의 유효성 — 방어 성패로 표본을 거르지 않음

사전 PLAN의 유효 표본은 동결 제품/조건, 정확 fixed tick 실행, native/runtime/관찰 오류·누락 없음, 초기 track0, 모든 초기 미사일의 native 종말 또는 사전 이탈 경계 도달을 뜻한다.

재사용한 이전 기능검증 fixture의 `nativeSensorUpdates`·`nativeAutoWeaponRelease`는 **관찰 지표**다. 탐지나 발사가 전혀 없었다면 그것도 전투 결과이며, 이 두 값이 false라는 이유로 실패 전투를 표본에서 제외하지 않는다. 기존 기능 fixture의 원 판정과 원 데이터는 보존하고, 통계용 유효성은 전체120개 raw를 같은 규칙으로 다시 읽어 정한다.

모델 오류·전송 누락·미종결·초기조건 불일치가 있으면 승인 판정을 하지 않는다. 정상적으로 끝났으나 방어하지 못한 사례는 포함한다. 이는 표본 탈락으로 성능을 좋게 만드는 것을 방지하는 처리이며, 시드·물리·종료 거리·주요 지표·검정·95% 구간·승인 기준은 바꾸지 않는다. 실제 합계 분석 전에 작성한다.
