# 최종 판정 기준

이 문서는 원래 테스트 기대값을 새 값으로 바꾸는 승인이 아니다.

1. 현재 pinned ACTIVE/SHADOW의 실제 packed 함수·모듈·보호 심볼·외부 asset을 증명한다. 과거 후보 결과를 최신 제품 통과로 재사용하지 않는다.
2. 새 양성은 실제 native 연관·교정으로 이어지고 진짜 동률/누락/차원오류/epoch불일치/신호·우도 충돌 음성은 HOLD한다. SHADOW는 원B ACTIVE 상태/private RNG를 보존한다.
3. >12 성분의 갱신 중단·확정 근거·처리시간을 각각 확인한다. synthetic soundness/성능 자료와 자연 RF에서 실제 발생한 성분 크기를 분리한다.
4. 실제 센서→트랙→AUTO→발사→종말/피격이 결정되는 동일 fixture를 A/원B SHADOW/원B ACTIVE/후보SHADOW/ACTIVE로 비교한다. unresolved timeout을 성공/종결전투로 세지 않는다. 관측 불가능한 identity swap은 임의로0이라 하지 않는다.
5. 원 paired4와D1419012는 원 strict 검사 그대로다. 단순히 내부 상태가 바뀌었다고 승인하지 않는다. 실제 결과/품질 근거로 결함·해소·정당한차이(사용자승인필요)·근거부족을 구별한다. 새로운 방어 악화는 원인을 보고하고 결과맞춤계수로 숨기지 않는다.
6. 기존 domain/UI/naturalWebGL/IFF/무표적/배속 검증을 수행한다. 상속419025FAIL/observer2미승인/legacy14INCOMPLETE는 분리한다.
7. C55/SPQ AIR live 미구현·범용 epoch/연관lineage·128초과bound·128dense비용 같은 한계는 별도 목록이다. 완료된 기능으로 합산하지 않는다.
8. 새 strict 기대값 갱신이 필요하면 old/new 원시값·해시·원인과 전투 증거를 제출해 **사용자 승인을 요청**한다. 승인 전 기대값0변경·FAIL유지. 구현 검증 PASS·증거완료·TRACK-B 전체완료·merge승인은 서로 다른 상태다.
