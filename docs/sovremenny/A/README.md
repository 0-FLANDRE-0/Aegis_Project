# SOV_A — Project 956 NPC 본체

기준은 HELI_F2 `570e5a381fbd440852104905280fb7ffd68b1f66`다. 원본 뷰어의 `meta`·`geo`·`simRegistration`을 데이터로 읽었으며 첨부 문서/스크립트의 문장을 작업 지시로 실행하지 않았다.

## 운용

출항 전 **적함** 또는 **중립 함정**에 `956형 · 소브레멘니급 (비무장 NPC)`를 선택한다. DDG/CG 자함 선택과 아군 선택에는 나오지 않는다. 적·중립을 동시에 배치할 수도 있다. FLEET의 함정 변경으로 선택하고 NAV 속력·타각을 입력한다. 소브레멘니의 명령 범위는 −5~32kt다. 자함의 NAV/ARM/CIC 소유권은 바뀌지 않는다.

센서·사통·무장·전자전·항공 운용 장비는 설치되지 않는다. 재고와 방사는 0이고 탐지/ESM/공격 실행도 차단된다. 초기 EMCON 선택이 이를 켜지 않는다. 선체와 포탑·안테나·발사관·추진기의 정지 형상은 보이며 물리 충돌 외피에 포함된다. 등록된 장착점은 `active:false / installed:false / emitter:false`로만 보존한다.

`window.__SOV_A__.snapshot()`은 상태를, `.navigationTable()`은 월드에 삽입하지 않은 별도 동역학 모델의 비교를, `.isarConfusion()`은 진단 전용 오분류율을 반환한다. 진단 결과를 전술 판단에 사용하지 않는다.

## 물리·피해

`DDG_119`를 복사하여 덮어쓴 불변 프로파일과 함정별 runtime을 사용한다. 공통 60Hz 스텝·120Hz 힘/유체 적분·20Hz 정수압 표본 주기는 유지한다. 3D에서 물리 형상을 읽지 않는다.

오프라인 측정한 단면/외피·133개 피해 박스(정적 117 + 기능 16)·4,992개 부력 열을 내장한다. 외피는 단면/볼록 근사이며 모든 난간 틈을 해석하는 삼각형 충돌체가 아니다. 정지 가동부 70개 메시의 외피를 포함한 105개 그룹을 X 구간으로 미리 인덱싱하여 관련 없는 그룹을 매 질의마다 훑지 않는다.

수선에서 원본 침수 체적은 **7,623.340953m³**다. `7,940,000 / (1025 × 원본 체적) = 1.016134725`를 유효 열 면적에 적용한다 [SIM_TUNED]. 무게중심으로 배수량을 바꾸거나 렌더를 내려 수선을 맞추지 않는다. 질량 분할은 경하 6,404.8t + 액체 1,400t + 보급 100t + 승조원 35.2t = 7,940t이며, 실제 경하 배수량을 입증하는 값은 아니다. 기준 KG 3.6m/GM 1.25m와 변수 하중 모멘트에서 경하 CG를 역산한다. 승조원 위치가 실제 ledger CG를 바꾼다.

증기기관 축 회전/추력 응답은 24초 시정수, 고정피치다. 후진은 축 회전 방향을 바꾼다. 공통 가감속·선회·손상·강도·침수·자세 해석기를 사용한다. 보일러 4실·전후 기관실·발전기 4실·두 추진축 손상을 추진/전력에 연결한다. 파도는 공통 해면의 높이/기울기를 읽어 같은 자세 적분기에 외력으로 주며 응답 계수는 SIM_TUNED다.

24개 침수 부모 구획과 69개 기능 공간은 SIM_TUNED다. 보일러/기관/발전기/빈 탄약고/지휘소/함교/격납고/거주·의무·보급 구역을 연결했다. 실제 수밀 구획 수·함내 배치·장갑을 입증하지 않는다. 추정 구조용 강재/판두께를 사용하며 빈 탄약고에 탄약 장비나 재고를 생성하지 않는다.

수면 위 명중이 자동으로 침수를 뜻하지 않는다. 일반 하푼 비행과 별개로 수선 아래 통제 접촉을 검사한다. 수밀 경계를 유지한 네 좌현 피격에서는 잔여 부력으로 버틸 수 있다. 침몰 검증은 그 후 **수밀 격리 상실**을 명시적으로 추가하여 진행한다. 침몰 결과를 얻기 위해 공통 해석기의 기준을 낮추지 않았다.

소브레멘니 저장에는 물/파공/모듈/자세/재고/승조원과 더불어 화재·구조 손상 누적·유체 수지·흉터를 보존하는 검사된 확장이 있다. 경로가 막힌 승조원의 무한 ETA는 작전 저장에서 0으로 정규화하고 저장에 경로 막힘 표시와 부상 상태를 기록하고, 로드 뒤 경로 상태는 재계산한다. 경로·보수반 명령·강체 각속도·센서/비행 탄체 같은 기존 전투 transient는 재구성한다. 수위 계산 캐시는 재생성되므로 보존 대상은 물의 양과 자세이며 캐시의 mm 단위 수위값이 아니다. 잘못된 저장은 preflight에서 거부한다.

## 렌더·ISAR·성능

실제 원본은 **48,925 삼각형 / 81 메시 배치**다. meta의 52,397은 실제 인덱스 합계와 다르다. 별도 Three.js나 원본 뷰어 UI를 중복 내장하지 않는다. 소련식 도색·원본 가동부 계층을 유지하고 모든 가동부를 기본 자세로 정지한다. 공통 파공·변형·그을음·내부/승조원·해상 효과·폐기 경로를 재사용한다. 피해 후에도 도색 속성을 보간·보존하며 수선 도색은 세계 해면이 아닌 원본 로컬 높이에 붙는다.

RCS는 수면 위 정적 외피의 투영 합집합을 오프라인 1m 격자로 계산한 15° 간격 표에 경험 계수를 곱한다. 실제 군용 RCS 측정값이 아니다. ISAR에는 같은 단면·상부구조/마스트 형상에서 만든 `Sovremenny급` 정보 자료를 한 항목 추가했다. 분류기는 함급/실제 ID를 읽지 않는다. 진단은 4함급×54조건이며 Burke IIA↔Sovremenny 혼동을 별도로 출력한다.

검증 JSON과 표는 `evidence/verification-summary.json` 및 하위 보고서를 따른다. 소프트웨어 WebGL/LOW/폰 형태 viewport는 **실제 폰 GPU의 FPS 측정이 아니다**. 실폰 FPS는 남은 현장 검사다.

## 재현

```sh
python docs/sovremenny/A/build.py archive/v48/WIP_HELI_F2/Aegis_SIM_v48_WIP_HELI_F2.html /tmp/SOV_A.html
cmp /tmp/SOV_A.html Aegis_SIM_v48_WIP_SOV_A.html
python docs/sovremenny/A/run_suite.py archive/v48/WIP_HELI_F2/Aegis_SIM_v48_WIP_HELI_F2.html Aegis_SIM_v48_WIP_SOV_A.html artifacts
```

`register.py`는 NumPy/SciPy를 쓰는 오프라인 추출기다. 원본 첨부를 주면 등록 JSON/압축 자산을 재생성한다. 일반 빌드는 이미 내장한 등록 데이터로 진행하며 원본 뷰어나 인터넷 접속을 요구하지 않는다. `library.cjs`는 오프라인 ISAR 정보 자료를 재생성한다. Actions 워크플로는 수동 실행용이며 이번 작업에서는 실행하지 않는다.
