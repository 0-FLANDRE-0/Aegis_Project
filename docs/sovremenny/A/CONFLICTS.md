# 구현 전 차이 보고와 처리

구현 전 사용자에게 아래 차이와 처리 방침을 보고했다. 기존 DDG/CG·Hawklink·식별/교전 결정을 우선하며 SOV_A만 확장한다.

1. **중립 배치/NAV**: 기존 배치는 아군/적군이며 FLEET 조작은 아군 전용이었다. 선택적 중립 슬롯을 추가하고 이번 비무장 956만 적·중립도 FLEET NAV로 지시한다. 아군·자함 선택과 전투/네트워크 명령은 허용하지 않는다. 기존 팀 네트워크의 아군 판정은 바꾸지 않는다.
2. **공개 제원의 차이**: GlobalSecurity/Wikipedia의 기준 배수량·흘수·속력 값이 다르다. 출처 값과 사용자 채택값을 모두 기록하고 7,940t/32kt/선체 약 6m를 채택한다.
3. **기준면**: 원본 수선을 sim Z0로 사용하고 선체 156.5m와 돌출부 bounds를 구분한다. CG 비행갑판 7.2/9.84m 같은 서로 다른 높이 기준을 재사용하지 않는다.
4. **실폰 검증**: 이 실행 환경에 실폰 GPU가 없다. 실제 Chromium·소프트웨어 WebGL·모바일 viewport의 프레임/드로콜/자원을 측정하고 실폰 FPS라고 표현하지 않는다.

추출에서 추가 확인한 사항:

- meta 52,397과 실제 인덱스 48,925 삼각형이 다르다. 실제 원본 지오메트리 합계와 렌더 수치로 검증한다.
- 원본 수선 체적과 7,940t은 약 1.6% 차이가 난다. 유효 부력 면적 보정을 SIM_TUNED로 명시하며 CG로 배수량을 바꿨다고 주장하지 않는다.
- 공통 작전 저장은 센서/탄체/경로/강체 각속도 등을 재구성한다. SOV의 지속 손상·침수·화재·흉터·수지는 별도 preflight 확장으로 보존하며 DDG/CG 저장 형식은 유지한다.
- 수밀 격리 유지와 상실은 다른 손상 조건이다. 침몰 검증의 격리 상실을 명시하고, 정상 수면 위 하푼 명중에 침수를 강제로 부여하지 않는다.
