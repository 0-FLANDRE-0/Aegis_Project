# 검증 환경

- Managed Linux, CPU quota4 cores / memory16GiB. 초기 병행 검사 뒤 시험 프로세스를 CPU0–3에 묶어 quota 주기 전체 정지와 브라우저 프레임 지연을 줄였다. 이는 OS 실행 배치만 바꾼 것으로 시뮬/미사일 코드와 시간 스텝은 그대로다. Node24.19.0, Python3.12.14, Chromium151.0.7922.173. 여러 측정/브라우저 프로세스를 겹쳐 실행했으므로 벽시계 시간은 단독 CPU 벤치마크가 아니다. 브라우저 회귀 중 전체 ENV 두 프로세스를 일시 중단했다가 같은 프로세스 그대로 재개했다. 출력 결과에 실행시각이나 CPU 스케줄은 포함하지 않는다.
- 원본 게임 HTML을 `https://aegis.test/`에 route하여 실제 출항 화면부터 검사한다. 2D headless backend의 `--disable-accelerated-2d-canvas`는 기존 시험 환경 보정이며, 물리 코드를 바꾸지 않는다. 3D는 실제 WebGL/SwiftShader다.
- 시험 전용 `live-fixture.js`는 버린 페이지에서만 삽입한다. 배포 HTML에는 넣지 않는다. 실제 시커/RF/EKF/INS/유도/신관/6DOF는 게임 함수를 사용한다. 시험 정보/손실 주입은 기존 검증용 관측 포트에서만 수행한다.
- ENV는 native source를 그대로 복사한 분리 scope다. 고정1/60초, private RNG/틱/배열, 이상 연속 표적 정보, 정지 해면 발사 조건이다. 실제 미사일 프로파일이나 실물 성능 자료를 입력하지 않는다. 모든 비교 숫자는 현재 가상 게임 모델의 출력이다.
- 동일 경로 검증은 전체 게임 페이지 안에 같은 이상 정보/발사 경계만 연결하고 실제 missiles 배열에 발사한 궤적과 private capsule의 궤적을 비교한다. 이 비교에서 네이티브 함수 본문은 변경하지 않는다. 자연 SPY 탐지→LOCK→정식VLS→전체 fixed tick 시험은 별도의 종합 회귀다.
- 배터리 시험은 실제 비행 뒤 시계 체크포인트를 사용한다. 자연480초 비행/실제 사거리 인증으로 부르지 않는다. 새 배터리나 종료 수치는 변경하지 않는다.
- 자연 SPY/전체월드8발은 목표 조종 AI를 유지한다. 초기 chaffCooldown만 길게 설정했고 이후 네이티브 AI의 변경까지 막은 것은 아니다. 원래 시험 스크립트의 method 문구를 전체 대응체계 비활성으로 해석하지 않는다.
- 실제 RF ON/OFF 첫 실행은 기존 시험에서도 작은 연속값 차이가 있었으므로 RF 전체 궤적의 비트 동일성을 주장하지 않는다. 기존 정상 명중을 새 종료기가 중단하지 않는지 판정한다. 반면 stage0/stage1/ENV_C의 독립 두 전체 실행은 원시 JSON bytes 동일성을 요구한다.
- 임시 빈 결과표가 들어간 후보 HTML에서 장시간 회귀를 실행하고, 계산표 내장 후에는 소스/데이터 대조, native audit, 프로파일 해시/변경 경고, 경계/최종 브라우저 검사를 다시 한다. 각 영수증의 실제 시험 HTML SHA를 유지하며 최종 SHA로 바꾸지 않는다.
- GitHub Actions는 수동 workflow만 준비하고 실행하지 않는다. main/이전 브랜치 병합이나 새 PR은 생성하지 않는다.
