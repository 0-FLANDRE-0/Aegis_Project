## 변경

- MR/ER/SM-6/ESSM Block 2 모두 Dynamic B4 포함. MR 17,500→22,500m, ESSM 3,500→7,500m 선반 상한; ER/SM-6 기존 상한·첨부 helper 수치 유지.
- 새 종료기는 RF EKF 추정 트랙, 유효성/신호 나이/신뢰도, 자기 INS와 신관 결과만 사용한다. 실제 표적 좌표·truth 조회·기존 closest/missedTarget 변수를 입력으로 삼지 않는다.
- 첨부 원안은 ARH 차단·SARH 유지 시 기존 명중 16조건을 12초에 조기 종료했다. 신선한 대체 SARH와 유효한 수신 DL 상태가 있으면 보류하도록 종료기만 보완했다. DL은 validity/source만 보며 좌표는 읽지 않는다.
- 종료 전용 교차 시계의 임의 65초 상한을 제거했다. 35km/200m/s는 175초다. Kappa 유도용 90초와 유도 계산은 그대로다.
- SM-6 게임 배터리 450→480초. MR 380 / ER 430 / ESSM 185초 유지. A/B OFF에서도 배터리는 적용한다.
- 신관·추진·항력·시커·Kappa 관련 기존 함수 166개 바이트 동일, NPC 문맥의 나머지 함수도 동일. 모델 자산 0–12와 UI/저장 경로 보존.

### 전체 월드 추가 검사

전투 트랙을 주입하지 않고 실제 SPY 관측으로 생성한 트랙을 선택·HOSTILE 지정·정밀추적한 뒤 정식 VLS 요청으로 발사했다. 타겟 조종 AI와 전체 simulateFixedTick을 유지했다. 초기 채프 쿨다운은 길게 설정했지만 이후 네이티브 AI를 교체하지 않았다. ON 실행은 실제 WebGL로 출항·발사·비행과 종료 후 렌더 진행을 확인했다.

## 남은 알려진 사격 결과 변화

**SM-6 / 100km / 5km / 접근 250m/s / seed 12002**: PIP_B는 78.033s에 명중한다. Dynamic B4 후 종료기 OFF도 148.517s에 SEA_IMPACT다. 별도 3회 반복에서 구판 3명중/신판 3비명중을 재현했다. 최근접은 약 131.75m다. 새 종료기의 조기 종료와 구분하며, 사용자 요청대로 B4 수치를 임의 변경하지 않았다. 모든 과거 사격 결과가 같다는 안정판 선언은 하지 않는다.

## 원안과 예비 시험의 실패도 보존

- 첨부 독립 9/9는 제공자의 기록으로, 이 작업의 통과 수에 합산하지 않았다. 실제 게임에서 발견한 원안 16개 조기 종료를 원시 로그와 함께 보존했다.
- 전체 RF 경로의 일부 첫 실행에는 0.283333s 시간 차이가 있었으며 같은 종료기 OFF끼리도 재현됐다. 원인 확정 없이 새 종료기의 힘/유도 변경으로 해석하지 않는다. 해당 함수의 바이트 보존과 명중 결과를 검증했다. 분리된 이상 진단/동일 네이티브 경로 비교는 5,894샘플 오차 0이다.
- 예비 3D 시험은 350ms 한 번의 프레임 샘플로 소프트웨어 렌더의 정지를 잘못 판정했고, 적 조종/채프가 있는 비명중에도 새 종료가 전혀 없어야 한다고 잘못 가정했다. 최종 시험은 다음 렌더 프레임을 기다리고 OFF의 실제 표적 결과와 비교한다. 예비 원본 결과와 실패 로그를 삭제하지 않았다.
- 자연 탐지 예비 배치의 정면 방향에서는 15초 안에 트랙이 생기지 않았다. 최종 자연 탐지 검사는 DDG face 중앙 45°에서 수행했다. 센서 모델은 수정하지 않았다. LOCK 하네스도 기존 MAP_A 커서 지정 절차에 맞춰 수정했다.
