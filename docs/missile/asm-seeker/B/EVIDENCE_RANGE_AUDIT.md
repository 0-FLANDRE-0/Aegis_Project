# ASM_SEEKER_B 거리·분해능 감사

- 660 수상/대조 조건 + 360 SAM ARH 조건, 오류 0.
- 45 km/200 m에서 함정 반사는 존재하지만 해면 셀과 unresolved composite가 되어 횡폭이 약 km급으로 증가하고 `.55` 아래로 거부된다.
- 폭은 `asmSeekerEchoMeasurement`가 임의로 더한 값이 아니다. 물리 member extent와 해면 셀 extent를 `asmSeekerCompositeReturns`가 전력 가중 RMS로 합성한 값이다. 해면 셀 횡폭 자체가 거리×빔 샘플링에 의존한다.
- 지시서식 SHADOW는 해면 0을 유지하고 채프를 모두 거부하며 ESSM/SM-6 항공기·ASM을 유지했다. 그러나 기존 정지 함정 10–30 km 획득을 잃으므로 ACTIVE 승격 불가다.
