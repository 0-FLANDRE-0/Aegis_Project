# ASM_SEEKER_B 원인 판정

1. **분해능 의존성 Confirmed.** 장거리 함정 에코가 beam-local sea cell과 unresolved composite가 되며, sea-cell 횡폭이 broad/flat 배경 감점으로 다시 사용된다.
2. **단순 분해능 중립화는 불충분.** 판단 불가 축을 가점·감점 모두에서 제외하면 정지 함정은 Doppler 두 항만 남아 기존 `.55`를 넘지 못한다. 임계값/가중치 재조정은 지시서상 금지이며 결과 맞춤이 된다.
3. **필요한 후속 관측량.** 동일 range-angle-Doppler cell 안에서 표적성 판단을 하려면 주변 해면 대비 국소 signal-to-clutter contrast, dwell 간 centroid/전력 지속성, 또는 waveform 기반 range/Doppler morphology가 필요하다. 이는 지시서가 “제안만” 허용한 새 특징이라 이번 제품에는 넣지 않았다.
4. **cue 바구니 부작용 Not confirmed.** 120조건 모두 기존 바구니 안이었다.
5. **공용 영향.** ESSM B2와 SM-6 IA 대공/대함 모두 같은 evidence 관문을 사용한다. SHADOW에서 항공기/ASM 통과는 유지되고 채프 통과는 제거됐지만, 수상/정지 표적 퇴행 때문에 전체 후보는 승인할 수 없다.
