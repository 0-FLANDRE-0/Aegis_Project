# 벙커힐 마스트 레이더 등록과 제원 근거

2026-10-03 확인. 사용자가 표시한 렌더 사진과 제공된 `BunkerHill_Articulated_Viewer_v5.html`의 원본 부품을 대조했다. 이 사진은 모델의 장착 위치를 정하는 근거이며 실제 함정의 개장 이력을 입증하는 자료로 취급하지 않는다.

## DDG-119와 다른 탐색 모델

SPQ-9는 30 RPM 단일 회전 스캔으로 2초 재방문을 사용한다. DDG-119의 기존 SPQ-9B는 30 RPM의 두 면과 기존 B형 프로세서를 유지한다. SPS-73은 자체 장착 높이·대역·튜닝을 적용하며 DDG의 BridgeMaster E 설정을 장비 제원으로 표시하지 않는다.

SPY의 SIM-TUNE은 DDG의 190 km SNR 기준 / 22 ms 전체 스케줄러 예산 / 11 ms 면별 예산과 CG의 185 km / 19 ms / 9.5 ms를 구분한다. CG의 극저고도 해면 계수는 0.22, 전이 지수는 0.90으로 두었다. 수신 오차·재방문 간격도 CG 전용이다. 이 값은 실제 레이더의 우열이나 기밀 성능을 뜻하지 않는다. 두 레이더의 표시 탐색 상한 320 km도 시뮬레이션 설정이다.

## 공통 처리 계약

반사·클러터 합성 이후에는 익명 관측만 트랙 계층으로 전달한다. SPQ-9와 SPS-73의 2D 관측에서 측정 고도를 만들어내지 않는다. 원본 구조물 삼각형의 사각은 센서 관측과 무장·조사기 사용 경로에서 검사하며 렌더 메시에서 실시간 물리 값을 읽지 않는다.

융합기의 기존 식별자 `SPQ9B`, `BRIDGEMASTER_E`, `SPY1DV`는 호환용 스트림 키로 남아 있다. 이는 CG에 실제 B형·BridgeMaster E·SPY-1D(V)를 장착했다는 뜻이 아니다. 장비 프로필, 표시 명칭, 회전 부품과 성능 프로세서는 선택한 함정의 설정을 사용한다.

재조회용 URL·HTTP 성공/실패·근거 발췌는 `radar-public-evidence.json`에 보존한다. 접근이 거부된 Navy 페이지나 존재하지 않는 페이지는 제원 근거로 인용하지 않는다.
