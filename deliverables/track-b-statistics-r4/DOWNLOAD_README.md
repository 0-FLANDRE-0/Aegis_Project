# TRACK-B R4 통계 검토 산출물

사용자 통계 조건을 충족한 R4 ACTIVE 승인본입니다.

HTML은 이전 R4와 byte 동일하며 이번 단계에서 게임 코드를 변경하지 않았습니다. HTML ZIP을 풀어 파일을 열면 됩니다. 별도 REPORT ZIP에 통계 표·사전 계획·시드·시험 소스·원시 로그·이전/새 기대값(승인된 경우)·미해결 항목을 포함합니다.

C55/SPQ AIR는 SHADOW-only입니다. 기존419025·friendly observer2·구형 EMCON UI14는 이 통계 결과로 해결 또는 승인한 것이 아닙니다. 과거 R4 보고서는 통계 전 보존 자료이며 최신 판정은 docs/contact/track/B_statistics_r4/REPORT.md를 따릅니다.

단독 HTML과 전체 시험 환경은 다릅니다. 재현에는 저장소·기존 Python/Playwright/Chromium·고정 참조 파일이 필요합니다. 새 실행은 기존 raw를 덮어쓰지 않는 작업사본에서 수행합니다.

실제 PR 병합·원격 readback은 별도 영수증을 확인합니다. 보고서 ZIP 작성 자체는 병합이 아닙니다.
